# CPU-only torch build on Linux/Docker (~200MB instead of ~3GB of bundled
# CUDA libraries). The +cpu wheel only exists on PyTorch's own index, hence
# the extra index. macOS has no +cpu variant -- its regular PyPI wheel is
# already CPU/MPS-only, so local runs on a Mac use that.
#
# To run on an NVIDIA GPU instead, replace the Linux lines below with:
#   --extra-index-url https://download.pytorch.org/whl/cu130
#   torch==2.14.0+cu130 ; sys_platform == "linux"
# and see "Running with CUDA" in the README (docker-compose.yml needs a
# change too).
--extra-index-url https://download.pytorch.org/whl/cpu
torch==2.14.0+cpu ; sys_platform == "linux"
torch==2.14.0 ; sys_platform != "linux"
